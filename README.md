# ⚡ QUICK START

## 📥 Clone Repository

```bash
git clone https://github.com/adiz777/adizala-portfolio.git
```

---

## 📂 Enter Project Directory

```bash
cd adizala-portfolio
```

---

## 📦 Install Dependencies

```bash
npm install
```

---

## 🚀 Start Development Server

```bash
npm run dev
```

---

## 🌍 Open In Browser

```bash
http://localhost:3000
```
